# 🏎️ Turbo Race Game

## Project Overview
Turbo Race Game is a desktop racing game developed using C# and Windows Forms in Visual Studio. This project demonstrates programming concepts and object-oriented design through an interactive racing experience.

## Features
- Racing game interface
- Vehicle representation and management
- Interactive gameplay
- C# Windows Forms interface

## Technologies Used
- C#
- .NET
- Windows Forms
- Visual Studio
- Object-Oriented Programming

## Project Structure
- `Form1.cs` – Main game interface and functionality
- `Form1.Designer.cs` – Windows Forms interface design
- `Program.cs` – Application entry point
- `Vehicle.cs` – Vehicle class
- `Vehicles.cs` – Vehicle management and related functionality

## How to Run
1. Download this repository.
2. Extract the downloaded ZIP file.
3. Open `TurboRaceGame.csproj` in Visual Studio.
4. Build the project.
5. Press F5 to run the game.
